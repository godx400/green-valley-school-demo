# Green Valley School — Next.js Pitch Demo

A responsive, multi-page school website and digital management demo built with Next.js App Router, TypeScript, and CSS.

## Requirements
- Node.js 18.17+ (Node.js 20 LTS recommended)
- npm

## Run locally
1. Extract this ZIP.
2. Open the project folder in VS Code.
3. Open a terminal in that folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Visit http://localhost:3000

## Pages
- `/` — Public school homepage
- `/parent` — Parent Portal demo
- `/parent/results` — Results page demo
- `/staff` — Staff Portal and role overview

## Demo roles shown
Headmaster, Deputy Headmaster, Discipline Officer, Bursar, Class Teacher, Subject Teacher, Academic Master, School Administrator.

## Important
All names, results, fee figures and school metrics are fictional. This is a pitch prototype only. Authentication, database persistence, role-based authorization, payment APIs, SMS/WhatsApp and server-side security are not implemented. External Unsplash images and Google Fonts require internet access. Replace sample content and remote images with approved school content before production.
